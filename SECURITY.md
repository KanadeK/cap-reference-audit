# Security

Supported version: 0.1.x. Runtime processing is local and makes no network requests.
Do not include confidential files or credentials in public reports.
Report vulnerabilities privately through GitHub's **Report a vulnerability** form
on this repository's Security tab. If unavailable, open an issue requesting a private
contact without including exploit details or sensitive data.

Inputs are untrusted data, never executable instructions. The documented input limits
bound ordinary workloads; run untrusted bulk data with OS memory/time limits as well.
